# Fleet Management Dashboard (Power BI)

## Overview

This project is an interactive Fleet Management Dashboard built using Power BI, designed to analyze and optimize logistics operations. It provides insights into fuel consumption, maintenance costs, driver performance and revenue trends.

## Objectives
Monitor fuel consumption & maintenance costs
Analyze driver performance
Track revenue trends and delivery metrics
Identify cost optimization opportunities
Improve customer retention strategies

## 📊 Dashboard Features

### Fleet Overview
Total Kilometers Traveled
Total Drivers
Total Liters Consumed
Monthly Maintenance Cost Trends

### Driver Insights
Driver-wise:
KM traveled
Fuel consumed
Maintenance cost
Fixed cost
Identify high-cost and low-efficiency drivers

### Revenue Insights
Total Revenue & Growth %
Total Goods Value
Total Orders Delivered
Revenue trends (Year vs Month)
Geographic revenue distribution (Map view)

### Customer Insights
% Customers with multiple orders
% Customers with single orders
Retention-focused insights

### Key Insights Panel

Actionable recommendations like:

Fuel & maintenance optimization
Driver performance improvement
Capacity planning
Customer retention strategies

## Dataset Used

The project uses the following datasets:

fCosts.xlsx → Fuel & maintenance cost data
fFreight.csv → Freight & delivery data
DimensionTables.xlsx → Supporting dimension tables
Dim States.xlsx → Geographic mapping data

## Key Insights

High percentage of repeat customers (98%) indicates strong retention
Fuel and maintenance costs vary significantly across drivers
Certain drivers show higher cost-per-km, indicating inefficiencies
Seasonal trends affect revenue and operational costs
